# v1.1.0

> ⚠️ **本 release 描述的字号行为是初版方案**。用户实际使用后反馈"字号不该联动 UI 整体布局"，后被 **v1.1.1 修订**：
> - 初版方案：`useFontSize` hook 同步改 `<html>` style.fontSize，所有 rem 单位联动重排
> - 修订后：撤掉 `useFontSize` / `applyFontSizeSync`，字号**只**影响 xterm 终端内的字符
> - 完整修订记录见 [`docs/releases/1.1.1.md`](./1.1.1.md)
>
> 本文件保留初版描述作为历史档案，但**实际行为以 v1.1.1 为准**。

## 变更

### ✨ 字号全局切换（rem 化）

- **12-24px 步进 2px 共 7 档**（小 / 标准 / 偏大 / 大 / 很大 / 超大 / 特大），默认 14px
- **三处入口**：
  - 工具栏步进按钮组（A− / 当前px / A+，disabled 边界自动禁用）
  - 快捷键 `Ctrl++` / `Ctrl+-` / `Ctrl+0`（前者实际 chord 为 `Ctrl+Shift+=`）
  - 字号按钮本体点击 → 重置 14px
- **`<html>` font-size 同步驱动**：所有 `rem` 单位元素联动重排（一次设值，全 UI 缩放）
- **防 FOUC**：`main.tsx` 在 React 首次 commit 之前同步应用字号，首屏零闪烁
- **持久化**：字号写入 Rust `AppConfig.font_size`，500ms debounce 自动写盘，下次启动恢复

### 🎨 终端字体切换

- **字体 Combobox**：列出系统等安装的字体 family（跨平台扫描，Windows DirectWrite / macOS CoreText / Linux fontconfig）
- **实时过滤**：输入框 substring 匹配，键盘 `↑↓` 移动高亮、`Enter` 选中、`Esc` 关闭
- **a11y 焦点管理**：打开 → 自动 focus 输入框；关闭（Esc / 点击外部 / 选中项）→ 焦点回到触发按钮
- **IME 友好**：中文输入法拼音合成期间不响应 `↑↓/Enter`，避免吞拼音
- **持久化**：选中字体名写入 Rust `AppConfig.font_family`，下次启动恢复
- **fallback 栈**：所有选中字体后拼 `Consolas, Monaco, 'Courier New', monospace`，字体缺失时优雅降级
- **`system-default` 保留字**：Rust / 前端统一识别，走 fallback 常量不拼前缀

### 🐛 修复 / 性能

- **xterm 字号切换 rAF 防阻塞**：>5k 行历史数据下避免主线程 50ms+ 卡顿，延迟到下一帧执行
- **xterm.refresh 强制 reflow**：字号/字体切换后显式 `refresh(0, rows-1)`，避免 xterm 只更新 metrics 不重排已渲染行
- **硬编码 px 尺寸 rem 化**（24px 字号下）：SerialToolbar / StatusBar / SendPanel / FontPicker 等组件无溢出/挤压
- **configStore 嵌套结构同步修复（reviewer CRITICAL #1）**：`sync()` 函数保留 `font_size`/`font_family` 字段，避免被 serial/UI store 覆盖
- **font-kit 单实现（reviewer CRITICAL #2）**：统一用 `SystemSource::all_families()`，删除占位冲突 API

## 用户视角

| 行为 | 路径 |
|---|---|
| 调字号 | 工具栏步进 `A−` / `A+`，或快捷键 `Ctrl++` / `Ctrl+-` / `Ctrl+0` |
| 改字体 | 工具栏"字体: 系统默认"按钮 → 输入关键字过滤 → 点击或 `Enter` 选中 |
| 持久化 | 改后等 500ms 自动落盘到 `%APPDATA%\com.ohmyserial.app\config.json` |
| 重启恢复 | 下次启动自动从 config.json 读回字号 + 字体 |
| a11y | `Tab` 可达触发按钮；打开后 `↑↓/Enter/Esc` 全部键盘可达 |
