# v1.0.2

## 变更

### 🎨 UI 修复

- **版本号动态读取**：状态栏右下角和终端欢迎语不再写死，改用 `src/utils/version.ts` 编译时 import `package.json` 的 version 字段，杜绝"binary 1.0.1 / UI v0.4.0"撕裂

### 📦 发布流程

- **GitHub Release 附 NSIS installer**：从此 release Assets 区有现成的 `OhMySerial_1.0.2_x64-setup.exe`，双击安装即可使用，无需 clone + build
- **`scripts/release.sh` 8 步自动化**：
  1. 预检（git 干净 / 在 main / gh 已登录）
  2. 同步三处 version 字段（Cargo.toml / tauri.conf.json / package.json）
  3. cargo check 重算 Cargo.lock
  4. 跑测试（cargo test --lib + tsc + vitest）
  5. commit + push
  5.5. `npm run tauri build` 产 NSIS installer
  6. git tag + push tag
  7. 读 / 生成 release notes
  8. `gh release create` + curl 上传 .exe

## 用户视角

| 行为 | 路径 |
|---|---|
| 下载 | 打开 release 页面 → 点 `Assets` 区的 `OhMySerial_1.0.2_x64-setup.exe` |
| 安装 | 双击 → NSIS 自动引导（自动装 WebView2 若缺失）→ 装到 `%LOCALAPPDATA%` |
| 启动 | 开始菜单启动 → 立即可用，零配置 |
| 配置 | 自动落到 `%APPDATA%\com.ohmyserial.app\config.json`（首次改设置时由 `useConfigSync` debounce 500ms 触发） |
| 日志 | `<exe 同目录>/logs/`（currentUser 模式可写），回退到 `%APPDATA%\com.ohmyserial.app\logs/` |

无管理员权限要求，无系统级服务注册。
